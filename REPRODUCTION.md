# Manual reproduction overview

This package preserves scientific source rather than providing a single launch command. Work on a local copy, install the listed dependencies, obtain the raw inputs, and review each stage's top-level input/output paths before execution. Use a short extraction directory on Windows, since some historical source-tree paths are long.

## Environment

The recorded research interpreter is Python 3.11.15. `environment/requirements-full.txt` records the existing package versions; `environment/conda-from-history.yml` is a smaller historical environment specification. Create your own environment, then install the dependencies. SGP4 and Skyfield support orbit handling; pyarrow and rosbags are needed for the optional GVINS stages. Packaging import checks were also performed using Python 3.12; that check does not replace numerical validation in the original environment.

Set `PYTHONPATH` to this package's `src` directory when using its portable scientific modules. For a preserved historical workflow, use that workflow's own frozen runtime and start from `manual_workflows/tree/`. Do not mix different frozen runtime snapshots in the same Python process.

## Input and path checks before running

Historical scripts retain strict identities, stage ordering and output protection. Some use relative paths, some build paths from their own file location, and some contain Windows long-path helpers. Configure those path variables for the local working copy before launching a stage. Updating a local path or deployment hash must never change a scientific threshold, candidate definition, observation interval or reporting epoch. Keep the original source hashes in `SOURCE_MANIFEST.json` as provenance.

No processed CSV/Parquet inputs, saved candidate records, wrapper observations, historical seals or result tables are shipped. Recreate them in the stated stage order; request exact historical input inventories from the corresponding author where required for an identical replay. This package has undergone source/hash/syntax/import checks, **not an end-to-end raw-data reproduction test**. Plot reproduction and publication artwork delivery are outside this source-only handoff.
