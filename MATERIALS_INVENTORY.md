# Materials inventory

This candidate contains source code, frozen configuration/protocol metadata, input identity indexes, environment records, original data links and manual reproduction documentation. It excludes manuscripts, supplements, correspondence, internal reviews, raw/processed observation arrays, saved numerical outputs and artwork.

Read README.md for entry points, CODE_FILE_CATALOG.md for individual source roles, DATA_SOURCES.md for provider links, and REPRODUCIBILITY_SCOPE.md for the current D120, Development and Motion–Clock additions. SOURCE_MANIFEST.json provides hashes; it is an inventory rather than a numerical reproduction certificate. Historical snapshots intentionally preserve separate runtime identities.
